# apple-design Skill 使用规则

Skill:
https://github.com/emilkowalski/skills/blob/main/skills/apple-design/SKILL.md

## 只需安装一次
不需要每个 Phase 重装。

## 必须重新读取的 Phase
- 0A：确认可用
- 5：AppKit Shell
- 6：Functional UI
- 7：Liquid Glass / Design Fidelity
- 7R：Sol Design Review
- Final：如涉及 UI sign-off，可再次读取

## 优先级
FROZEN 产品决策
>
apple-design Skill 通用建议

Skill 可以优化：
- spacing
- typography
- native controls
- accessibility
- Apple convention

Skill 不可以：
- 增加 Hover
- 改状态逻辑
- 改 B capsule
- 去白色线框
- 改 Usage/Settings 结构
- 改技术栈
